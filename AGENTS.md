# PerfumeBooth Project Rules & Guidelines

## 1. Automatic Memory Management
*   **Mandatory Rule**: Whenever you complete a feature, bug fix, architectural modification, test suite run, or significant project milestone, you **MUST automatically update [`memory.md`](file:///d:/Full-Perfumebooth/memory.md)** in the project root before finishing the turn.
*   **What to update in `memory.md`**:
    1.  `Current Context & Focus`: Keep active objectives and system status accurate.
    2.  `Completed Milestones`: Record the newly completed feature, fix, or verification.
    3.  `Next Steps`: Ensure upcoming actionable steps are up to date.

## 2. Engineering Standards
*   Follow the *Ponytail, lazy senior dev mode* principles: minimal code, YAGNI, standard library first, zero boilerplate, and always verify with runnable checks.
*   Preserve existing docstrings, API contracts, and security boundaries.
